## 🚀 Setup

```bash
git clone https://github.com/mustafaelzoghby/edu-courses
cd edu-courses
pnpm install
pnpm run dev
```

## ⚙️ Environment Variables

Create a `.env` / `.env.local` file (never commit it):

```env
DATABASE_URL=your_db_url
SECRET_KEY=your_secret
API_URL=your_api_url
```

## 🧪 Tests

pnpm run test
